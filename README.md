# University News Monitoring Service

Сервис для автоматического мониторинга и сбора новостей с сайтов вузов (РЭУ, РТУ МИРЭА, КФУ) в единую базу SQLite с последующим формированием персональных рассылок по интересам пользователей.

---

## Стек технологий
* **Python 3.13+**
* **Менеджер пакетов:** `uv`
* **Парсинг:** `BeautifulSoup4`, `requests`
* **Обработка данных:** `pandas`
* **База данных:** `SQLite3`

---

## Структура проекта

```text

│   └── parser_rea.py       # Парсер РЭУ им. Плеханова
